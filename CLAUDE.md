# Portfolio Monitor

A Python project to monitor a personal stock portfolio and send sell alerts to Discord.

## Important context about me

- I am a beginner programmer. I understand CS concepts (data structures, algorithms) but have never built a complete project before.

- Please ALWAYS propose a plan in plain English before writing code, and wait for me to approve.

- When you write code, explain what each new function or file does and why.

- Prefer simple, readable code over clever or short code.

- If I seem confused, slow down and explain. I'd rather build slowly and understand than build fast and not.

## Stack

- Python 3.11+

- yfinance for stock prices

- JSON files for config and state (no database)

- Discord webhook for alerts

- GitHub Actions for scheduling (added in week 1, day 5)
